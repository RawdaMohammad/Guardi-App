# Guardi App

A user-friendly Flutter emergency response app that facilitates quick and easy assistance requests during critical situations. We seek to improve communication 
between users, emergency services, and trusted contacts. Our goals include enhancing user safety through a faster and more effective emergency response system, ultimately empowering users with a reliable tool for a safer environment. 

## 🚀 Features

- Panic buttons for different emergency cases, but to access most of the services (police, fire, ambulance), the app will ask the user first to access his/her location; it will then be used to connect the user with the nearest emergency unit. 
- After pressing the panic buttons 3 times, confirmation is needed from the user, and cancellation is also available to avoid false alarms. 
- By saying a reserved word, the user can request emergency service. 
- Some features are available offline (ex, first aid instructions, natural disasters). 
- The user can switch mode to be a volunteer, and he/she must submit proof. 
- The user could request a volunteer in an emergency, like a car broken to get help. 
- Guardi also ensures the users' safety on their trips by sharing them with emergency contacts, and they get notified if the trip time is up.

## 🛠 Tech Stack

- Flutter & Dart
- Laravel & PHP
- MySQL
- Firebase (Firestore)
- Flask (Integration between CNN model and Flutter)
